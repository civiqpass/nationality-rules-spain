# Spanish nationality by country of origin: open data (CiviqPass)

36 countries of origin and 8 situations: years of legal residence (Código Civil art. 22), whether the DELE A2 and the CCSE are required, and the fee. Each row carries its source in the BOE or the Ministerio de Justicia and the day it was read.

**CiviqPass is not an official site.** This is a compilation of public texts. Check the source on each row before you apply.

## Files

| File | Content |
|---|---|
| `nationality-rules-by-origin.csv` | One row per country of origin: years, DELE A2, CCSE, fee, source URLs, read date. |
| `nationality-rules-by-situation.csv` | The 8 situations that change the residence period. |
| `nationality-rules.json` | Everything in one file. |
| `nationality-rules.schema.json` | JSON Schema for the file above. |

Online version, in Spanish, English, French and Arabic: https://civiqpass.com/es/datos and https://civiqpass.com/open-data/nationality-rules
